Spiral Drop — 内部试玩版
================================

这是什么
  去掉内购与次日回归礼的完整游戏，供内部游玩。
  - 钻石商店（含结算里的「+」、天赋树的购买按钮）不会出现
  - 次日回归礼不会弹
  - 刷新次数用完后会自动免费补 1 次（代替「看广告补刷新」）
  - 其它玩法、UI、存档与正式版一致

怎么玩（本机）
  双击 start.bat → 浏览器自动打开 http://localhost:8000/index.html
  需要本机有 Python 3（没有的话装一个，或用任意静态服务器指向本目录）

怎么发给别人
  把整个目录打包成 zip，上传到任意静态托管（GitHub Pages / Cloudflare Pages /
  Netlify / Vercel 都行），把链接发出去即可，手机和 PC 浏览器都能直接玩。
  注意：必须通过 http(s) 访问，直接双击 index.html（file://）打不开。

操作
  PC：按住鼠标左键左右拖动 → 旋转平台
  手机：手指左右滑动 → 旋转平台

存档
  存在浏览器本地（IndexedDB）。换浏览器 / 清缓存会丢档。
